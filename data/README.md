# Data Layout

Raw datasets are intentionally excluded from this scaffold.

Place data according to the configured paths:

- data/aviation/raw/
- data/aviation/processed/
- data/maintie/raw/
- data/maintie/processed/
- data/splits/
- data/stress_tests/
- data/manifests/

Never overwrite raw files. Store SHA-256 hashes, record counts, source information and license notes under data/manifests/.

# Project Guide — Maintenance IE Benchmark

Master reference for the thesis: *NLP-based structured information extraction and
planning support in maintenance work orders.* Covers data safety, environment setup,
the full run order, where every result lives, and the file map.

---

## 0. CRITICAL — never lose this data

These files are **irreplaceable** (weeks of hand-annotation) and must be backed up
before anything else. Everything else can be regenerated by re-running scripts.

| Path | What it is | Why irreplaceable |
|---|---|---|
| `outputs/gold/*.jsonl` | 1,600 hand-corrected gold records (pilot 300, round1 500, rare1/2/3) | manual annotation |
| `outputs/splits.json` | frozen test/dev split | changing it invalidates all comparisons |
| `config/schema.yaml` | 9 entities + 11 relations, the schema | defines the whole task |
| the corrected Label Studio exports | source annotations | your ground truth |

**Back these up now, three ways:**
1. **Git** (do this once):
   ```
   cd "D:\information extraction\maintenance-ie"
   git init
   git add config outputs/gold outputs/splits.json scripts src *.md *.txt
   git commit -m "Gold data + pipeline (1600 records)"
   ```
   Then push to a private GitHub repo (`git remote add origin ...; git push`).
2. **Cloud copy**: copy `outputs/gold/` + `outputs/splits.json` + `config/schema.yaml`
   to Google Drive / OneDrive.
3. **The Claude Project** attached to this chat also holds a snapshot of decisions/results.

## 1. Environments (Miniconda, created once)

Three isolated envs — your pipeline on modern versions, each external model on its own.
Each has a `requirements-*.txt` in the repo; freeze a `.lock.txt` after install for the appendix.

| Env | For | File |
|---|---|---|
| `maintie` | Tiers 1-3 + all scoring/reporting | `requirements-maintie.txt` |
| `spert` | official SpERT | `requirements-spert.txt` |
| `rebel` | REBEL (later) | `requirements-rebel.txt` |

```
conda create -n maintie python=3.11 -y && conda activate maintie
cd "D:\information extraction\maintenance-ie"
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements-maintie.txt
pip freeze > env-maintie.lock.txt
```
(repeat for `spert` with `requirements-spert.txt`.)

Always `conda activate maintie` before running pipeline commands.

## 3. Run order

### A. Your pipeline (env: maintie)
```
python scripts/09_report.py --tiers 1 2 3 --tune --save-models --bootstrap 1000 --run-id gold1600
python scripts/10_significance.py --tiers 1 2 3 --seeds 3
```

### B. SpERT (train in spert env, score in maintie)
```
conda activate maintie && python scripts/06_export_spert.py
conda activate spert   && python spert/spert.py train --config spert/configs/avimaint_spert.conf
conda activate maintie && python scripts/06b_import_spert_preds.py "outputs/spert/log/avimaint_spert/<timestamp>/predictions_test_epoch_20.json"
```

### C. (optional) DAPT experiment
```
python scripts/08b_domain_pretrain.py           # writes outputs/dapt/encoder
# set schema encoder to outputs/dapt/encoder, then:
python scripts/09_report.py --tiers 3 --tune --save-models --bootstrap 1000 --run-id gold1600_dapt
# set encoder back to distilbert-base-uncased afterwards
```

### D. THE combined comparison (env: maintie) — everyone in one table
```
python scripts/09_report.py --tiers 1 2 3 --bootstrap 1000 \
       --spert outputs/reports/spert_test.json \
       --external REBEL=outputs/reports/rebel_test.json \
       --run-id gold1600_full
```
Drop `--external ...` until REBEL exists.

## 4. Where results live (one place)

| File | Contents |
|---|---|
| `outputs/reports/tables/overall_metrics.csv` | **master table** — every model, entity+relation F1 + 95% CI |
| `outputs/reports/figures/` | comparison charts, per-tier training curves, confusion |
| `outputs/reports/metrics_full.json` | full per-class breakdown |
| `outputs/reports/tables/significance_pairs.csv` | paired-bootstrap significance between models |
| `outputs/reports/tables/seed_variance.csv` | mean ± std across seeds |
| `outputs/models/<version>/` | versioned saved models + `model_card.json`; `registry.csv` indexes all runs |

`overall_metrics.csv` is the single source of truth for the thesis results table.

## 5. Current results (gold 1600, frozen 225-record test set)

| Model | Entity F1 | Relation F1 |

| Tier 1 · CRF | 0.934 | 0.780 |
| Tier 2 · BiLSTM | 0.943 | 0.685 |
| Tier 3 · DistilBERT | 0.941 | 0.829 |
| SpERT · BERT | 0.943 | 0.841 |

Significance (paired bootstrap): on relations SpERT > CRF > BiLSTM, all significant;
on entities all models tie. Entities are saturated; relations discriminate the models.

## 6. Script map
